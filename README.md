# 🃏 德州扑克训练工具集（Texas Hold'em Trainer）

一套**纯前端、单机离线**的德州扑克训练工具，专为「数学不好、靠直觉打牌」的学习者设计。
核心思路：把概率公式全部换成**数数、做倍数、比大小**——全程最大的运算量是"13 减 4"和"乘 4"。

> ⚠️ 仅供个人单机练习使用，不涉及任何真实货币与赌博。

## 工具组成

| 文件 | 说明 |
|---|---|
| `德州扑克数牌直觉训练器.html` | 5 面板训练器：数补牌（Outs）、2和4法则速算、跟弃比大小决策、13×13 起手牌色块表、14 天训练计划 |
| `德州扑克多人牌局模拟器.html` | 完整牌局模拟器（主力工具，见下） |
| `德州扑克单机牌局模拟器.html` | 早期单挑版模拟器（保留作对照） |

## 多人牌局模拟器功能

- **完整牌局流**：发牌 → 盲注 → 翻前/翻牌/转牌/河牌四轮下注 → 摊牌 → 结算
  支持过牌/跟注/下注/加注/全下/弃牌，标准边池结算、平分底池、全下自动 runout
- **1~5 个 AI 对手**：按钮位轮转、单挑特例、位置化策略全部正确
- **AI 博弈心理**：每人随机性格系数（攻击性 0.6~1.6），会轻 3bet 诈唬、盲注防守、临界牌心理跟注、翻后诈唬开火——不会见到加注就秒弃
- **下注交互**：预设尺寸按钮（最小 / ½池 / ¾池 / 满池）+ ± 步进器（每次 1BB）
- **结算透明**：牌桌下方明细面板列出每人底牌、牌型、收回金额；净盈亏 = 收回 − 本局投入
- **整局统计**：VPIP（翻前入池率）、激进度 AF、赢池次数、净筹码，附健康区间对照
- **AI 自适应**：上一局你的战绩会保存在 localStorage，重开一局 AI 集体调整凶狠程度
- **训练提示**：实时显示位置、筹码档、听牌 outs×4/×2 估算、所需跟注比例、左右比大小决策
- **手机适配**：6 人桌单屏放下所有手牌与下注，46px+ 触控目标
- **🤖 托管模式**：整桌全 AI 自动连续对打，可当牌局演示观看

## 使用方法

无需安装任何依赖，浏览器直接打开 HTML 文件即可（推荐 Chrome / Edge，手机浏览器亦可）。

建议训练路径：先用训练器练熟「数 outs」→ 开着提示打 20 手模拟器 → 关提示自己数、再开核对 → 按训练器第 5 面板的 14 天计划推进。

## 技术要点

- 单文件 HTML，零依赖、零构建
- 标准 7 选 5 取最优牌型评估（9 大牌型 + 平分判定）
- 质量保障：Node 打桩 DOM 后跑数百手全 AI 自动对战回归（0 错误 + 筹码守恒校验）
